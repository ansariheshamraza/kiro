# 🚀 RachnaX – Structured Content Creation Assistant (Frontend)

RachnaX is a modern front-end web application designed to help students and beginner creators transform raw ideas into structured, platform-ready content.
This project focuses on clarity, guided thinking, and clean user experience using modern web technologies.

## 🌟 Project Overview

RachnaX demonstrates:

- Structured content flow design
- Clean SaaS-style UI
- Scroll-triggered animations
- Typewriter demo simulation
- First-visit animated loader
- Fully responsive layout
- Modern interaction design

This repository currently contains the front-end implementation.

---

## 🛠 Tech Stack

- HTML5
- CSS3 (Flexbox & Grid)
- JavaScript (Vanilla JS)
- GSAP (GreenSock Animation Platform)
- ScrollTrigger
- sessionStorage (for loader logic)

## 🎯 Key Features

- ✨ Smooth GSAP animations
